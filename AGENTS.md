# Главное правило проекта ANNITI SMART

Утверждённый пользователем шаблон и визуальный дизайн сайта заморожены.

- Без предварительного явного одобрения пользователя нельзя менять композицию, сетку, размеры, отступы, типографику, цвета, фон, изображения, форму элементов, порядок секций или адаптивное поведение утверждённого дизайна.
- Разрешено изменять функциональность внутри существующего интерфейса, только если это не меняет утверждённый внешний вид.
- Перед добавлением любой новой видимой функции, кнопки, блока, состояния или другого визуального элемента сначала нужно подготовить изображение будущего результата в контексте текущего сайта и получить явное решение пользователя: «разрешаю» либо команду переделать.
- До такого одобрения запрещены реализация в основной версии сайта и развёртывание визуального изменения.
- После одобрения каждый новый элемент обязан использовать существующие цвета, шрифты, сетку, интервалы, линии, радиусы, изображения и общий визуальный язык сайта.
- Из референса переносится только явно согласованная область; соседние блоки и элементы не считаются автоматически одобренными.
- Если функцию невозможно добавить без изменения утверждённого дизайна, работа останавливается на стадии изображения для согласования.

Это правило имеет приоритет над предложениями улучшить, переосмыслить или переработать дизайн по инициативе разработчика.
